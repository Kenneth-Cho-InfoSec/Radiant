# Radiant 0.1.0

Radiant 0.1.0 is the first private Android beta of Radiant, an independent Android adaptation of the open-source LYNX-SHARE DAW.

## Device support

- Android 10 or newer
- ARM64 devices
- Tablet-optimized responsive layouts, with compact phone layouts

## Included

- JUCE-based Android host for the existing C++ DAW engine and editing surfaces
- Android project picker support for `.lynx` and `.radiant` files
- MIDI import and export through Android document pickers
- Supported FL Studio project import using the upstream parser
- Android playback foreground service
- Radiant launcher artwork and bundled license notices

## Known limitations

- This beta has not passed the full public-release acceptance checklist.
- The release APK signature and package were verified, but this exact release variant was not installed on a device during this build.
- The Pixel 8 debug-build capture shows the portrait top control strip clipped at the right edge.
- Long-session audio, physical recording, low-latency performance, Bluetooth and USB audio routing, and thermal behavior still need device testing.
- Representative FL Studio projects and complete plug-in state round trips need broader validation. Desktop plug-in binaries are not loaded on Android.
- Android audio export and save behavior still needs more validation.
